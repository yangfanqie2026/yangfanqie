# 🍅 洋柿子的工作台

一个**三端通用**（电脑 / 平板 / 手机）的个人工作台 Web App（PWA），支持账号登录、云端同步。

包含四个模块：**每日计划 · 四级英语学习 · 运动 · 每日热点新闻**，莫兰迪可爱风格。

---

## 一、功能一览

| 模块 | 功能 |
|---|---|
| 📋 每日计划 | 每天自动生成 1~2 条随机小计划；可勾选完成、删除、手动新增；进度条 |
| 📚 四级英语 | 每日打卡（连续天数）、CET-4 高频单词（可标记掌握）、语法知识点卡片（可收藏），按天轮换 |
| 🏃 运动 | 每日打卡、记录运动类型与时长、设置每周目标并看进度 |
| 📰 每日热点 | 国际热点 / 政治热点 两个分类，实时拉取（接入第三方新闻 API，未配置 Key 时显示示例） |

所有数据随账号**云端同步**：在电脑上打了卡，手机、平板上自动同步。

## 二、在你自己电脑上先试试（最简单）

不需要懂代码，照做即可：

1. 安装 Node.js（官网 https://nodejs.org ，选 LTS 版，一路下一步装好）。
2. 进入本项目文件夹，双击运行 `启动.bat`（Windows）或在文件夹地址栏输入 `cmd` 后执行 `npm install` 再 `npm start`。
   - Mac / Linux：在终端里 `cd` 到本项目目录，执行 `npm install` 然后 `npm start`。
3. 浏览器打开 http://localhost:3000 ，注册一个账号就能用了。

> 这一步只是本地试玩。要让手机、平板也能用，需要下面的"部署到免费云平台"。

---

## 三、部署到免费云平台（让三端都能用）

推荐用 **Render**（免费、不用绑卡）：

1. 注册 GitHub 账号（https://github.com ）。
2. 在 GitHub 新建一个**空仓库**（比如叫 `yangfanqie`）。
3. 把本项目里的**所有文件和文件夹**上传到这个仓库（直接拖拽即可，或按 GitHub 网页提示）。
4. 打开 https://render.com ，用 GitHub 登录，点 **New + → Web Service**。
5. 选择刚才的仓库，按下面填：
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Instance Type**：选 **Free**
6. 点 Create Web Service，等几分钟，得到一个网址（形如 `xxx.onrender.com`）。
7. 用电脑/手机浏览器打开这个网址 → 注册账号 → 开始使用。
8. **手机当 App 用**：用手机浏览器打开网址 → 点浏览器菜单的「添加到主屏幕」→ 桌面就出现一个🍅图标，点开像 App。

> 提示：免费版在你长时间不用时可能会"睡"几分钟，第一次打开稍慢，正常。

## 四、开启"实时新闻"（可选）

默认新闻显示示例。要显示**真正的实时新闻**，去天行数据（https://www.tianapi.com ）注册一个免费账号，拿到 API Key，然后在部署平台的环境变量里加：

```
NEWS_API_KEY=你的key
```

保存后重新部署即可。不配也能正常使用，只是新闻是示例内容。

## 五、文件结构

```
yangfanqie/
├── server.js              # 后端：账号、同步、新闻代理
├── package.json
├── data/                  # 运行时自动生成的数据（用户数据存这里）
└── public/                # 前端界面
    ├── index.html
    ├── styles.css         # 莫兰迪可爱风格
    ├── app.js             # 页面逻辑
    ├── content.js         # 预置内容：单词/语法/计划任务池/运动类型
    ├── manifest.webmanifest
    └── sw.js              # 离线/加到主屏支持
```

## 六、想自己加内容？

打开 `public/content.js` 就能改：
- `planTemplates`：每日计划随机任务池
- `words`：CET-4 单词（想加更多直接按格式加）
- `grammar`：语法知识点卡片
- `sportTypes`：运动类型

改完保存，刷新页面即可生效。

---

## 七、小提示

- 记住你的账号密码（目前没有"找回密码"，忘记就只能重新注册）。
- 免费云平台的数据存在服务器磁盘上，日常使用不会丢；只有你手动"重新部署"时可能清空，重要内容建议截图备份。
